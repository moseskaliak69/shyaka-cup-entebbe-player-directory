SHYAKA CUP ENTEBBE — TOURNAMENT APP v1

1. In Supabase SQL Editor, run supabase-tournament-upgrade.sql once.
2. Keep your existing player-files Storage bucket and admin user.
3. Upload/commit all files in this folder to the existing GitHub repository root.
4. Vercel will redeploy the same connected project automatically.

Features in this build:
- 24 named teams found in the official fixture + 1 placeholder for the confirmed 25th team
- 56 fixture slots (46 scheduled + 10 knockout)
- player directory with existing 47 players/photos/licences
- admin login
- add players online
- enter match results
- automatic standings
- results and tournament statistics
- knockout stage view
- mobile-friendly public website
